🛡️ Usage Limits & Terminal Conditions

Device Protection

To keep your mobile phone or desktop browser fast and prevent memory freezes, TextMaster enforces the following transparent operational rules:

  • ✅
    Repetition Range: Minimum repetition count is 1 and maximum repetition count is 10,000 per generation.
  • ✅
    Safe Output Memory Limit: Expected output size is calculated before generation. By default, outputs above 1.5 MB trigger a memory warning, and outputs exceeding your configured safety ceiling (default 5 MB, hard maximum 10 MB) are blocked rather than freezing your browser.
  • ✅
    Zero Silent Truncation: TextMaster never silently cuts off or truncates your generated output. Either the complete requested repetition is generated or a clear size warning is shown.
  • ✅
    Strict Input Validation: Negative numbers, decimals, empty numbers, or malformed settings are automatically rejected.
  • ✅
    Safe Text Rendering: User input is handled strictly as plain text and is never executed as HTML or JavaScript.
  • ✅
    Honest Browser Capabilities: Clipboard copying and file downloads rely on standard browser permissions. TextMaster never runs hidden scripts, background tasks, or automatic downloads, and never transmits your text to external servers.

🔒 Privacy Policy

Last Updated: October 2026

1. Local Browser Execution

The core text-repetition and text-editing functionality of TextMaster operates locally within your web browser. Text entered into the core tools is processed in your device's memory and is not intentionally uploaded or transmitted to an external application server by TextMaster.

2. No Account or API Key Required

TextMaster does not require you to register an account, provide a password, or supply any API key to use its features.

3. Local Downloads & Clipboard Access

  • Downloaded Files: When you click the "Download TXT" or "Download JSON" button, the file is generated locally by your browser using standard Blob URLs. No data is sent to a server.
  • Clipboard Access: TextMaster accesses your device clipboard only when you explicitly activate a "Copy" or "Paste" action and when your browser permissions allow it.
  • Local Preferences: Non-sensitive user interface preferences (such as theme mode, font size, and default repetition settings) are stored locally in your browser's localStorage where supported.

4. Hosting Providers, Browser Settings & External Links

While the TextMaster application logic itself does not transmit your input text to a backend, please note that web hosting providers, content delivery networks, or your browser vendor may collect standard server access logs. Selecting external links—such as the official Instagram profile link—will direct you to third-party platforms governed by their own privacy policies.

5. Contacting the Developer

If you have questions regarding this Privacy Policy, you may contact the developer (Cartoon Ladki) through the official Instagram profile or via the configured email method listed on the page.
