Device Protection

To keep your phone or desktop browser fast and prevent memory freezes, TextMaster enforces these transparent operational rules:

  • ✅
    Repetition Range: Between 1 and 10,000 repetitions per generation.
  • ✅
    Safe Output Memory Limit: Outputs above 1.5 MB trigger a warning, and outputs exceeding your configured ceiling (default 5 MB, max 10 MB) are blocked rather than freezing the browser.
  • ✅
    Zero Silent Truncation: TextMaster never silently cuts off generated output. You either get the full result or a clear size warning.
  • ✅
    Strict Input Validation: Negative numbers, decimals, empty numbers, and malformed settings are rejected.
  • ✅
    Safe Text Rendering: User input is handled strictly as plain text — never executed as HTML or JavaScript.
  • ✅
    Honest Capabilities: Clipboard and download actions rely on standard browser permissions. TextMaster never runs hidden scripts or background tasks.

Privacy Policy

Last updated: October 2026

1. Local Browser Execution

The core text-repetition and text-editing functionality of TextMaster operates locally within your web browser. Text entered into the core tools is processed in your device's memory and is not intentionally uploaded or transmitted to an external application server by TextMaster.

2. No Account or API Key Required

TextMaster does not require you to register an account, provide a password, or supply any API key to use its features.

3. Local Downloads & Clipboard Access

  • Downloaded Files: Files generated by the "Download TXT" or "Download JSON" buttons are created locally by your browser using standard Blob URLs. No data is sent to a server.
  • Clipboard Access: TextMaster accesses your clipboard only when you explicitly trigger a "Copy" or "Paste" action, and only when browser permissions allow.
  • Local Preferences: Non-sensitive UI preferences (theme mode, font size, default repetition settings) are stored in your browser's localStorage where supported.

4. Hosting Providers, Browser Settings & External Links

While the application logic does not transmit your input text to a backend, web hosting providers and CDNs may collect standard server access logs. External links (such as the official Instagram profile) direct you to third-party platforms governed by their own privacy policies.

5. Contacting the Developer

If you have questions regarding this Privacy Policy, you may contact the developer (Cartoon Ladki) via the official Instagram profile or through the configured email method on the .
